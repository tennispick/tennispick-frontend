# Gemini Project Guidelines

This document outlines the key architectural and styling conventions for the tennispick-frontend project.

## Core Technologies

- **Framework**: Next.js
- **Styling**: TailwindCSS

## Development Principles

- **Business Logic**: Implement business logic using functional programming principles. Favor pure functions, immutability, and composition.
- **Code Structure**: Organize and structure the code using classes where appropriate, particularly for models or services, to encapsulate data and related behavior.

## Language

- **Response Language**: Please respond in Korean.
